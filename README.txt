Reels Enhancer for Instagram (v4.2)
===================================

ENGLISH

Install
1. Unzip this file into a folder you won't delete.
2. Open chrome://extensions and turn on "Developer mode".
3. Click "Load unpacked" and pick the folder that has manifest.json.
   Updating? Replace the files and press the reload button on the extension.
4. Reload Instagram. If you still have the Tampermonkey script, turn it off.

Click the extension icon to change settings or switch the language (EN / ES).
Alt+Shift+R turns everything on or off.
Press ? on a reel to see all keyboard shortcuts.

ESPAÑOL

Instalación
1. Descomprimí este archivo en una carpeta que no vayas a borrar.
2. Abrí chrome://extensions y activá "Modo de desarrollador".
3. Tocá "Cargar descomprimida" y elegí la carpeta que tiene manifest.json.
   ¿Actualizando? Reemplazá los archivos y tocá el botón de recargar de la extensión.
4. Recargá Instagram. Si todavía tenés el script de Tampermonkey, desactivalo.

Tocá el ícono de la extensión para cambiar opciones o el idioma (EN / ES).
Alt+Shift+R activa o desactiva todo.
Apretá ? sobre un Reel para ver todos los atajos.

Requires Chrome 111+ (also Edge, Brave, Opera).
